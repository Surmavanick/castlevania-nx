Castlevania-NX v1.0.0
=====================

This is an unofficial Nintendo Switch port of the Xbox Live Arcade version of
Castlevania: Symphony of the Night, based on NocturneRecomp 1.4.5.

YOU MUST SUPPLY YOUR OWN LEGALLY OBTAINED GAME.

Supported default.xex SHA-256:
26a58b074c5dd6185b77a8111a0012866d11cba674b4b0810d79dbf07ad68aa6

INSTALL
-------

1. Copy castlevania-nx.nro, and optionally the supplied
   nocturnerecomp.toml, to:

   sdmc:/switch/castlevania-nx/

2. Either copy your extracted XBLA files to:

   sdmc:/switch/castlevania-nx/game/

   or put the original LIVE/CON/PIRS package in:

   sdmc:/switch/castlevania-nx/package/

   The second method extracts into game/ on first launch.

3. Hold R while starting an installed title to open the full-memory Homebrew
   Menu, then launch castlevania-nx.nro. Do not use Album/applet mode.

If used, the sidecar must remain named nocturnerecomp.toml.

PERFORMANCE
-----------

The validated route ran at 60 Host FPS and 60 Guest FPS with CPU 1963.5 MHz,
GPU 998.4 MHz and memory 2131.2 MHz. Stock-clock performance is unmeasured;
60 FPS at stock clocks is not promised. Overclocking is optional and at your
own risk.

The decorative animated cloud outside the gameplay viewport is intentionally
disabled for performance. No gameplay-area rendering artifacts were observed
in the validation run.
