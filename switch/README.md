# Switch icon

`icon-public-source.png` is original artwork generated specifically for Castlevania-NX
with OpenAI image generation. `icon-public.jpg` is its 256x256 Homebrew Menu derivative.
Neither file was extracted from Castlevania or another game, and both are distributed
under this repository's MIT license.

Final generation prompt, summarized: an original gothic night emblem with a generic castle
silhouette on a cliff, a pale full moon, mist and a small crimson ribbon accent; centered,
high contrast and readable as a square icon; no characters, franchise artwork, logos, text
or watermark.

Switch builds deliberately do not link NocturneRecomp's desktop window icon, because that
icon is generated from the user's own `default.xex`.
